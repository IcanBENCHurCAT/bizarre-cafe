## 2026-08-04 - [Hono Middleware and SSE Broadcaster Performance]
**Learning:** In Hono, middleware factory functions (like \`rateLimiter\` returning a \`MiddlewareHandler\`) must be invoked before being passed to \`app.use()\`. If passed without invocation (e.g. \`app.use('/api/*', rateLimiter)\`), Hono treats the factory as the middleware itself, causing it to run on every request. This caused a major memory leak due to \`setInterval\` in the rateLimiter. For SSE, broadcasting O(N) where N is all connected clients is a severe bottleneck, indexing by room ID (O(1) lookup) is necessary.
**Action:** Always check that middleware factories are invoked before passed to \`app.use()\` when setting up Hono routes, and maintain indexes for collections to avoid full scans on frequent real-time operations.
